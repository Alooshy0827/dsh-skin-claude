## 真实客户端

用官方安装包自带 CLI 创建全新的隔离 Web profile，以本地链接加载仓库根目录，并且只监听本机地址。个人 DSH 配置和应用程序文件未修改。

[runtime.json](../qa/v0.1.0/runtime.json) 绑定生成客户端和实际 DOM 样式哈希，记录主题切换、输入、刷新、插件停用恢复、窄窗口及浏览器控制台检查结果。[plugin-geometry.json](../qa/v0.1.0/plugin-geometry.json) 保存同一滚动位置启用和停用皮肤时的 29 个按钮与开关测量结果，所有位置及尺寸一致。截图来自真实客户端，未使用重画的页面模型。
